# Quản lý chất lượng Tổ Toán

THPT Đoàn Thị Điểm – Hà Nội.

**Chuẩn bị GitHub Pages:** xem [TRIEN_KHAI_GITHUB_PAGES.md](TRIEN_KHAI_GITHUB_PAGES.md). Chạy `npm test`, `npm run build`, `npm run check:pages`; GitHub Actions tự triển khai `pages-dist` khi push nhánh main. Build này không ghi đè bản dist cũ hoặc dữ liệu hiện có.

**Mở `dist/index.html` để xem thử ngay.** Có thể tải riêng tệp này lên thư mục gốc GitHub và bật GitHub Pages.

Đọc **[HUONG_DAN.md](HUONG_DAN.md)** để thiết lập Supabase, tài khoản thật, nhập Excel, sao lưu và chuyển năm học.

Mục tiêu đã thống nhất được lưu tại **[MUC_TIEU_YEU_CAU.md](MUC_TIEU_YEU_CAU.md)**. Kết quả kiểm tra và các phần chưa xác minh được ghi tại **[KIEM_THU.md](KIEM_THU.md)**.

Bản mẫu chứa 216 học sinh giả lập và lưu riêng trên trình duyệt. Chưa cấu hình Supabase thì chưa có đăng nhập bảo mật hoặc đồng bộ dữ liệu thật giữa giáo viên.

Không tải danh sách học sinh, bảng điểm, bản sao lưu hoặc khóa dịch vụ lên kho GitHub công khai.
